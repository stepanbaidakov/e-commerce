# Интернет-магазин
## Описание:
Интернет-магазин для возможности совершения покупок в любое время

## Установка
Клонируйте репозиторий:
1. ```git clone https://github.com/stepanbaidakov/e-commerce.git```


## Использование 
* Возможность создания товаров из двух классов `Smartphone` и `LawnGrass`
* У созданных товаров есть возможность складывать общую стоимость одинаковых
товаров, выводить информацию о товаре в консоль, а также задавать новую цену
* Для упрощения пользователю при создании товара сразу выводится в какой товар был создан
## Документация
Для получения дополнительной информации обратитесь к [документации]
* Класс `BaseProduct` включает в себя все возможные товары, также существуют отдельные классы под
товары трава газонная и смартфоны. 
* Товары распределяются на категории (класс `Category`), а так же добавляются в заказ (клас `Order`)
