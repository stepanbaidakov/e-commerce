# Интернет-магазин
## Описание:
Интернет-магазин для возможности совершения покупок в любое время

## Установка
Клонируйте репозиторий:
1. ```git clone https://github.com/stepanbaidakov/e-commerce.git```


## Использование 
Возможность создания товаров из двух классов `Smartphone` и `LawnGrass`
У созданных товаров есть возможность складывать общую стоимость одинаковых
товаров, выводить информацию о товаре в консоль, а также задавать новую цену
